# Spaces demo

Examples of what you can make in a Kunobi space: plans, tools and games for everyday life and for work. Open `index.mdx` for the gallery.

## Open it in Kunobi

In a Kunobi build with Git import (local, dev or unstable), add a space with **From a Git URL…** and paste this repository's URL. Kunobi clones it into your spaces folder and opens the gallery.

## Make one yours

Every example reads its data from one file in its own `data/` folder. Change that file, or ask your AI to, and the page follows. Each page shows two prompts to start with.

| Example | Folder | Data |
| --- | --- | --- |
| Finding a home, together | `home-hunt/` | `data/homes.json`, `data/people.json` |
| A weekend in Lisbon | `trip/` | `data/places.csv` |
| A 40th birthday party | `event/` | `data/guests.json`, `data/event.json` |
| Shared house costs | `expenses/` | `data/expenses.md`, `data/group.json` |
| Dinners this week | `meals/` | `data/week.csv`, `data/recipes.json` |
| Sol Bakery team space | `team/` | `data/tasks.csv`, `data/team.json`, `wiki/` |
| Monthly report | `monthly-report/` | `data/report.json` |
| Hiring, side by side | `hiring/` | `data/hiring.json` |
| Content calendar | `content-calendar/` | `data/posts.json`, `data/calendar.json` |
| Dino Snack | `dino-snack/` | `KID` at the top of `index.mdx` |
| Quiz Night | `quiz-night/` | `data/quiz.json` |
| A birthday film | `birthday-film.mdx/` | `data/film.json` |
| Seed pitch | `pitch-deck.mdx/` | `data/deck.json` and the slide text in `full.mdx` |
| Felipe, in 3D | `scan-viewer/` | `data/scene.json` |

Pages show data and do not save changes made on the page; edits happen in the data files. The people, numbers and places are made up.
